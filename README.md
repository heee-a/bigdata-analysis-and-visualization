# 大数据分析及数据可视化 · 中国林业资源（2015–2024）

基于国家统计局、国家林业和草原局、中国林业信息网等**权威公开数据**，对近十年我国森林资源规模、木材生产、林业产业与造林结构进行整理，并以**高级交互式可视化**呈现（非基础条形/饼图）。

> 配套仓库主张：用动态时间序列、分级填色地图、雷达对比、仪表盘、桑基图、主题河流图、象形柱图、箱线图、平行坐标、气泡图、漏斗图等高级可视形式，把"十年增绿"讲清楚。

## 一、数据来源（均已标注于页面与代码）

| 指标 | 来源 |
| --- | --- |
| 林业产业总产值（年度，亿元） | 中国林业信息网(lknet.ac.cn) 年度数据；2023/2024 来自绿皮书/国土绿化公报 |
| 木材产量（年度，万 m³） | 行业统计 / 观研天下整理（2010–2024） |

| 人工林面积、生态服务价值、林地资产 | 国家林草局、国家统计局《中国森林资源核算研究》 |

## 二、关键发现（十年增长）

- **林业产业总产值**：5.94 万亿（2015）→ **10.17 万亿**（2024），增长约 **+71%**，2024 年林草产业年产值突破 10 万亿元。
- **木材产量**：6832 万 m³（2015）→ **13740 万 m³**（2024），增长约 **+101%**。
- **森林覆盖率**：22.96%（2018，第九次清查）→ **25.09%**（2024），已超过"2030 年国家自主贡献"目标，**提前达标**。
- **森林蓄积量**：170.58 亿 m³（2018）→ **209.88 亿 m³**（2024），超 200 亿，提前实现 2030 目标。
- **人工林面积**约 8000 万公顷，**居世界首位**；首批设立 **5 个**国家公园。

### 本轮新增的补充内容（其他相关维度）
- **木材供需与对外依存度（2015–2024）**：木材产量由 6832 万 m³ 增至 13740 万 m³；进口量由 7117 万 m³ 降至 6284 万 m³；对外依存度由 51.02% 降至 **31.38%**，国内供给保障能力增强（来源：观研天下 2010–2024）。
- **林草生态“家底”（2024）**：林地 42.53 亿亩、草原 39.12 亿亩、湿地 8.34 亿亩、沙化土地 25.09 亿亩（来源：国新办 2025-09-10 新闻发布会）。
- **生态效益**：森林年碳汇量 2023 年达 **12 亿吨以上**；森林生态服务价值 15.88 万亿元（2018）；集体林业每年带动 **4000 多万**农民就业；森林旅游与休闲 39.06 亿人次（2019）。
- **林业产业构成（2019）**：第一产业 2.53 万亿、第二产业 3.62 万亿、第三产业 1.93 万亿；支柱行业含经济林种植与采集（1.51 万亿）、木材加工及木竹制品（1.34 万亿）、森林旅游与休闲（1.54 万亿）。
- **省级林业产业 TOP（2018）**：广东 8168 亿、山东 6736 亿、福建 5924 亿、广西 5708 亿、浙江 4898 亿等。

## 三、可视化组件（共 26 类高级图表 + 数据总表）

**交互增强**：顶部**目录导航**可一键跳转各图；**时间轴联动**——拖动/播放 ① 时间轴时，④ 仪表盘与"年份快照"面板同步切换到对应年份；多数图表右上角内置**数据视图**（查看/导出原始数据）与**保存图片**工具栏；面积图与木材图支持**缩放游标（dataZoom）**；地图可缩放拖拽并以涟漪高亮 TOP5；底部**数据故事**区块随滚动揭示四个关键结论。

1. **时间轴动画**——页面加载即从 2015 自动播放，观看林业产值与木材产量逐年绘制的动态时间序列。
2. **中国省级森林覆盖率地图**——Choropleth 分级填色，呈现"南高北低、西北低"的空间格局，TOP5 以涟漪高亮（运行时联网加载地理边界）。
3. **多维雷达对比**——覆盖率 / 蓄积量 / 面积 / 人工林 / 生态价值归一化，对比 2018 与 2024。
4. **森林覆盖率仪表盘**——现状值 vs 2030 目标，进度一目了然。
5. **林地结构桑基图**——全国 3.24 亿公顷林地的地类构成流向。
6. **造林方式主题河流图**——2015–2019 各造林方式面积随时间的"河流"演变。
7. **双轴渐变面积折线**（带缩放）——产值与木材产量双 Y 轴增长轨迹。
8. **木材供需与对外依存度**（带缩放）——柱状+折线双轴：产量、进口量与对外依存度（2015–2024），呈现依存度由峰值 54.71% 降至 31.38% 的"木材安全"故事。
9. **林业产业构成旭日图**——三次产业及其支柱行业的层级占比（2019）。
10. **省级林业产业 TOP 矩形树图**——按产值面积映射对比林业大省（2018）。
11. **多维指标年际热力图**——5 个异量纲指标逐年归一化，观察协同增长。
12. **林业生态系统关系图**——力导向知识图谱串联"森林资源—生态效益—经济社会"三大维度。
13. **七大区域森林覆盖率 · 象形柱图**（新增）——用"树木"符号高度表示各区域平均覆盖率，直观体现"南高北低"。
14. **七大区域覆盖率分布 · 箱线图**（新增）——统计分布视角，展示各区域省份覆盖率的中位数与离散程度。
15. **多维指标年际 · 平行坐标图**（新增）——5 个归一化指标并排，观察各年份在多维空间的整体跃升。
16. **省级覆盖率 vs 产业产值 · 气泡图**（新增）——横轴覆盖率、纵轴 2018 年产值，气泡大小映射产值规模，揭示资源与产业空间错位。
17. **林业产业构成 · 漏斗图**（新增）——2019 年总产值→二三一产的层级集中度。
18. **省级林业产业 TOP10 · 南丁格尔玫瑰图**（本轮新增）——以半径表征产值规模，比饼图更强调量级差异，呈现林业大省梯队分布。
19. **林业生态体系分类 · 树图**（本轮新增）——正交 Tree 展示"森林资源—生态效益—经济社会"三大分支及关键指标层级，与 ⑫ 关系图互补。
20. **世界主要国家森林对比 · 气泡图**（本轮新增）——横轴森林面积、纵轴覆盖率、大小映射面积，将中国置于全球坐标观察"面积大、覆盖率中等"特征（数据：FAO FRA 2020）。
21. **林业发展综合指数 · 多折线**（本轮新增）——将产值、木材产量、蓄积量、覆盖率以 2015=100 归一化，观察"增绿"与"增收"同步跃升。
22. **十年累计造林面积 · 阶梯面积图**（本轮新增）——对 2015–2024 造林面积累计求和，呈现总量轨迹（标注 2021 起口径调整）。
23. **2030 战略目标进度 · 多仪表盘**（本轮新增）——森林覆盖率、森林蓄积量、木材自给率三项对照国家中长期目标，均已达标或改善。
24. **核心指标相关性矩阵 · 热力图**（本轮新增）——产值/木材产量/蓄积量/覆盖率/造林面积五项指标的 Pearson 相关系数矩阵，揭示"增绿—增收"协同关系。
25. **林业三次产业产值演变 · 堆叠柱**（本轮新增）——2017/2019/2023 三年一、二、三产业构成对比，观察第三产业比重上升。
26. **各省森林覆盖率 · 棒棒糖排序图**（本轮新增）——34 个省级行政区降序排列，圆点按七大区域渐变着色，清晰呈现"南高北低、西北垫底"。
27. **数据总表**（新增）——年度核心指标、木材供需、省级覆盖率（降序）、三次产业四张可横向滚动的数据表，与图表同源，便于核对。

> **年份快照联动**：① 时间轴（播放或拖动）会驱动 ④ 仪表盘与年份快照面板实时显示该年的覆盖率（插值估算）、产值、木材、蓄积量、森林面积、造林面积；时间轴默认从 2015 年起播。

附：**`assets/forest_demo.svg`**、**`assets/forest_demo_timber.svg`**、**`assets/forest_demo_region.svg`** —— 自包含动画演示文件（浏览器打开自动循环播放，无需任何依赖），分别演示"产值/木材产量十年增长""木材对外依存度下降""七大区域覆盖率树木成长"，可作为"视频/动图演示"随附。由 `tools/make_demo.py`（纯标准库）生成。

open index.html        # 或双击用浏览器打开

## 五、重要口径说明（务必阅读）

1. **关于"树木数量"**：我国**不发布"全国树木总棵数"**这一指标。描述森林资源规模的权威定量指标是**森林面积、森林蓄积量（活立木）、森林覆盖率**。本项目以此为准，未作臆造。
2. **森林覆盖率 / 蓄积量 / 面积**来自每 5 年一次的全国森林资源清查。图中"插值估算"的年度值（如 `coverageEst`、`stockEst`）仅为满足"逐年展示"趋势演示而做的**线性插值**，并非官方年度值，已在页面与数据文件中明确标注。
3. **造林面积**自 **2021 年起统计口径调整**（国土绿化公报口径），与 2020 年及以前的"造林总面积（含封山育林、退化林修复等）"**不可直接比较**，页面已加注说明。
4. 三次产业产值 2023 年为基于占比趋势的估算值，已在 `data.js` 标注。
